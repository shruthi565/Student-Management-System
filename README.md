# Student Management System

A simple **console-based Student Management System** developed using Python.

## Features

* Add student
* View students
* Search student
* Update student
* Delete student
* Calculate average marks
* Check Pass/Fail
* Find top student
* Store data using JSON

## Technologies

* Python
* JSON

## Concepts Used

* Functions
* Lists & Dictionaries
* Loops & Conditions
* File Handling
* Exception Handling
* JSON

## How to Run

```bash
python student_management.py
```
